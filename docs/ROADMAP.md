# Langkah pengembangan berikutnya
- [ ] P0 — Guru memvalidasi tiga contoh, variasi daun dan nama ilmiah; catat referensi serta tanggal tinjauan. Selesai jika seluruh contoh memiliki bukti kurasi.
- [ ] P0 — Inventarisasi 10–20 tumbuhan sekolah tanpa mengasumsikan jenis yang tersedia. Buat daftar spesimen dan foto berizin.
- [ ] P1 — Susun ulang kunci sesuai koleksi lokal; uji semua jalur dan contoh di luar koleksi. Hasil yang tidak cocok harus tetap belum teridentifikasi.
- [ ] P1 — Tambahkan kartu visual morfologi dan riwayat jalur alasan.
- [ ] P1 — Tambahkan lembar observasi dan refleksi, penyimpanan lokal serta ekspor JSON/CSV. Beri cara menghapus catatan dan hindari data pribadi siswa.
- [ ] P1 — Uji kelas kecil: akses ponsel, keyboard, keterbacaan, kesalahan pilihan dan pemahaman alasan.
- [ ] P2 — Tambahkan CI pengujian data dan kode, dokumentasi kontribusi, serta keputusan lisensi oleh pemilik.
- [ ] P2 — Evaluasi kebutuhan offline/PWA, pengelolaan data guru dan integrasi PUSPAMANAH setelah MVP stabil.
- [ ] P2 — Tentukan hosting dan prosedur rilis setelah persetujuan pemilik; scaffold ini tidak melakukan deployment.
